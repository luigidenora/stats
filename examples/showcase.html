Graph showcase

Each card runs the real overlay in Performance mode (the memory leak in Memory mode), fed with simulated data. The mode plate (display icon and code) steps to the next mode on each click; the caret beside it, or a right click, opens the list. Readouts sit bottom-left with the mode’s graphs beside them: frame, CPU and GPU apart, merged into one RGB graph only when there is no room.
